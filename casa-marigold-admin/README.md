# Casa Marigold

Requires Node.js 18+. No npm install needed.

    ADMIN_PASSWORD="your-password" node server.js

Windows (cmd):

    set ADMIN_PASSWORD=your-password && node server.js

- Site: http://localhost:3000
- Admin: http://localhost:3000/admin

Menu data lives in `menu.json`. Back it up if you move servers.
Put the server behind HTTPS when you deploy it.
